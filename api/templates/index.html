What this is

CyberHash Toolkit is a hands-on way to learn cryptographic hashing: what each algorithm is actually good (or bad) for, how hash identification works from format alone, and why unsalted fast hashes fall quickly to a dictionary or small keyspace search.

Everything here runs server-side in Python's hashlib — no third-party crypto libraries, so you can read exactly what's happening in core/hasher.py, core/identifier.py, and core/analyzer.py.
